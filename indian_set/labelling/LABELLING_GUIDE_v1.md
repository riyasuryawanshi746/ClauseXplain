# Labelling guide (no legal background needed)

For each row, decide what the text is MAINLY about and write one category from the list, exactly spelled.
Put `y` in `not_a_clause (y)` instead if the row is a heading, definition, party/date block, table-of-contents line, signature block, or a fragment too cut off to read as a clause. Leave `your_category` empty in that case.
Do not look at any other labels. Do not use AI tools. Work alone.

| Category | Use when the text is about |
|---|---|
| Assignment | transferring the agreement or rights to someone else; successors/assigns; subcontracting |
| Commercial Terms | scope of services, pricing structure, minimum commitments, revenue share, obligations to provide inputs |
| Confidentiality | keeping information secret, non-disclosure, return/destroy information |
| Dispute Resolution | arbitration, mediation, negotiation of disputes, dispute procedure |
| Force Majeure | events beyond control (war, flood, strikes) excusing performance |
| Governing Law / Jurisdiction | which law applies, which courts have jurisdiction |
| Indemnification | one party compensating/holding harmless the other for losses or claims |
| Intellectual Property | ownership or licence of IP, copyright, documents ownership |
| Liability | limits or caps on liability, exclusion of damages |
| Modification | amending the agreement, waiver, entire-agreement style change rules |
| Non-Compete | restrictions on competing or exclusivity |
| Non-Solicitation | not hiring or soliciting staff/customers |
| Other | a real clause that fits none of the above (e.g. notices, severability, survival, language) |
| Payment | fees, invoices, retention money, taxes, when and how money is paid |
| Penalties | liquidated damages, deductions or fines for delay or breach |
| Privacy / Data Protection | personal data, data location, logs, data security |
| Termination | ending the agreement, notice, grounds for termination, compensation on termination |
| Warranty | guarantees, standards of performance, defect liability, representations |

Tie-breaks: pick the closest single category. If two fit, choose the one the first sentence is about, and write the other in `notes`.
